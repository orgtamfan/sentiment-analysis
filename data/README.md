# Reddit Comment Dataset: CS2 vs. VALORANT

## 1. Folder structure

```text
data/
  raw/
    +-- cs2_comments_raw.csv       # Raw comments from r/GlobalOffensive
    +-- valorant_comments_raw.csv  # Raw comments from r/VALORANT
    +-- reddit_comments_raw.csv    # Combined raw dataset (CS2 + VALORANT)
```

## 2. CSV schema

Each CSV file contains the following columns:

- `game`: Game label (`CS2` or `VALORANT`)
- `subreddit`: Source subreddit (`GlobalOffensive` or `VALORANT`)
- `post_id`: Reddit post ID
- `post_title`: Post or thread title
- `post_url`: Post URL
- `comment_id`: Unique comment ID
- `comment_text`: Original comment text (no lowercasing, stop-word removal, stemming, or punctuation removal)
- `comment_score`: Net upvote/downvote score
- `comment_created_at`: Comment creation time in ISO 8601 UTC format
- `author`: Comment author's username (metadata)
- `scraped_at`: Scrape timestamp in UTC

## 3. Data integrity notes

- Comment text is preserved in its original form for later preprocessing.
- Comments marked `[deleted]` or `[removed]` were automatically filtered during collection.
- Duplicate `comment_id` values were automatically removed.

## 4. Dataset files and analysis roles

- **Raw collection data:** Raw files belong under `data/raw/` and are excluded from Git. The schema above describes the archived raw CSV format. The `prepare_labels` command currently reads a JSON list whose records contain `game` and `comment_text`; a raw CSV must first be exported or converted to that input format.
- **VADER review file:** `data/processed/reddit_comments_label_review.csv` is generated from the raw JSON. It contains `sentiment_suggestion`, while `sentiment` is blank and `review_status` is `needs_review`.
- **Full labeled analysis input:** `data/processed/reddit_comments_labeled.csv` is a separate, locally maintained file with `game`, `text`, and `sentiment`. It may contain manually reviewed labels (`reviewed`) or explicitly retained VADER labels (`vader_auto`). The historical full-scale report uses VADER labels for 5,000 comments per game.
- **Manual annotation input:** `data/processed/manual_label.csv` is a separate, locally maintained annotation file used for inter-annotator agreement and the primary Model B evaluation. The manual sample contains the first 300 comments from each game's 5,000-comment set; these comments were mixed in the annotation sheet and independently labeled by three annotators. The final label is assigned by majority vote in the `Hasil_Gabungan` spreadsheet and stored as `sentiment_final`. This file is not generated by the VADER preparation script.
- **Report snapshots:** `data/processed/*/` contains committed historical metrics and class-distribution reports, not the underlying comment rows. `reports/` is the analysis output directory; two files currently tracked at the repository root are `reports/model_metrics.json` and `reports/sentiment_distribution.csv`.

The VADER-labeled full set, the 600-comment VADER subset, and the 600-comment manual subset are distinct experiments. Do not treat their scores as directly interchangeable or describe the full VADER-labeled set as fully hand-annotated.

The scrape was reported to take one day on October 18, 2026, around 9 p.m. Jakarta time (WIB, UTC+7); exact start and end times are not recorded. The 5,000-comments-per-game target was a hard cap, not a census of eligible comments. The first 300 comments from each game's set were selected for manual annotation and mixed in the annotation sheet. This is not documented as random sampling, so selection bias is possible. The scraper/query settings, source ordering basis, and detailed post/comment selection criteria are also not recorded here. The annotation classes and majority-vote procedure are described in the main README; preserve the original annotation guide and collection log with the research materials.
